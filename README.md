# 大家经方 · 经方学术思维模拟器

> 《伤寒论》《金匮要略》学术思维模拟器 —— 融合胡希恕、黄煌、曹颖甫、刘渡舟、郝万山、王琦、黎庇留等经方大家学术思想。

## ⚠️ 安全声明（最高优先级）

本 Skill **严格限定为中医学术推演模式**，所有输出仅供学习参考，**绝对不构成医疗建议、诊断意见或处方凭证**。

- 🚨 请勿根据本 Skill 的输出自行购买、煎煮或服用任何中药材
- 🚨 急危重症请立即拨打 120 或前往正规医院急诊
- 🚨 本 Skill 拒绝开具任何形式的正式处方

## 📦 功能特性

- **方-病-人 诊疗模式**：整合黄煌体质学说、胡希恕六经八纲、刘渡舟六经辨证
- **38 首核心经方五维结构**：方证抓主症 / 体质画像 / 药证加减铁律 / 方剂鉴别诊断 / 禁忌红线
- **方证相应裁决机制**：阳性症状群 → 六经归属 → 匹配度评分（满分100）→ 阈值（≥85）裁决
- **十问歌结构化问诊**：严格按照张景岳"十问歌"顺序，每次只问一条核心问题
- **腹诊引入**：胸胁苦满为柴胡证，腹硬满为承气证，腹软无力为建中/理中证
- **六大类方三角速查**：太阳、少阳、少阴、厥阴、阳明、太阴类方鉴别
