| 主症 | 鉴别要点 | 六经归属 | 候选方 |

## 🎯 综合辨证决策树

```
[用户主诉]
    │
    ├─ 发热恶寒同时？
    │   ├─ 无汗脉浮紧 → 太阳伤寒 → 麻黄汤类
    │   └─ 有汗脉浮缓 → 太阳中风 → 桂枝汤类
    │
    ├─ 寒热往来？
    │   ├─ 胸胁苦满 → 少阳 → 小柴胡汤类
    │   └─ 兼便秘心下急 → 少阳阳明 → 大柴胡汤
    │
    ├─ 但热不寒？
    │   ├─ 大汗大渴脉洪大 → 阳明经证 → 白虎汤
    │   ├─ 便秘腹满痛拒按 → 阳明腑证 → 承气汤
    │   └─ 但头汗出、渴不欲饮 → 阳明湿热 → 茵陈蒿汤
    │
    ├─ 但寒不热/四肢厥冷？
    │   ├─ 脉微细、下利清谷 → 少阴寒化 → 四逆汤
    │   ├─ 心下悸浮肿 → 少阴水泛 → 真武汤
    │   └─ 脉弦、阳郁不达 → 厥阴热厥 → 四逆散
    │
    ├─ 寒热错杂？
    │   ├─ 上热下寒、久利 → 厥阴 → 乌梅丸
    │   ├─ 心下痞满不痛 → 中焦 → 半夏泻心汤
    │   └─ 心烦不卧 → 少阴热化 → 黄连阿胶汤
    │
    └─ 杂病类？
        ├─ 痰饮咳喘 → 小青龙汤
        ├─ 腹中诸疾痛（女）→ 当归芍药散
        ├─ 癥瘕痛经（女）→ 桂枝茯苓丸
        ├─ 脉结代心动悸 → 炙甘草汤
        └─ 腰痛脚弱、小便不利 → 肾气丸
```
